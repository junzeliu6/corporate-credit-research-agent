## 数据完整性与限制

- FY2024及FY2025短期借款主表可比值：已核对报表行未形成FY2024和FY2025短期借款数值事实；不能把空白单元格直接解释为零。（需要结合报表列结构、借款附注和银行授信资料进一步确认。）
- 重大变动原因：V2.2仅完成主表数值及确定性变动识别，尚未逐项抽取附注中的管理层解释。（原因分析需在后续报告质量优化中关联附注证据，不能由模型补造。）
- 短期借款 FY2024 尚未形成可比事实
- 短期借款 FY2025 尚未形成可比事实
- 仅使用S01（2025年报）和S10（2024年报）的合并财务报表主表行；S11已登记并解析，留作后续扩大跨报告复核。
- 金额统一保留年报原始人民币元精度，未把万元或亿元格式化结果写回事实层。
- 所有同比、比率和重大变动阈值均由确定性 Python 函数计算，未交由 LLM 判断。
- 重大变动和风险信号仅用于确定进一步核查方向，不等同于授信风险定性结论。
