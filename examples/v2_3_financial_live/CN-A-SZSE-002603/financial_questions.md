# 财务尽调问题清单

- 请说明营业收入、净利润及经营活动现金流重大变动的业务原因，并提供订单、回款及费用明细支持。
- 请提供货币资金受限情况、银行账户清单及最新银行对账资料。
- 请提供短期借款、长期借款、授信额度、抵质押和担保明细；当前年报主表未形成FY2024/FY2025短期借款可比事实。
- 请说明应收账款账龄、前五大客户、逾期及期后回款情况，并核查收入确认和回款匹配。
- 请说明存货构成、库龄、跌价准备、周转变化及主要产品备货安排。
- 请说明固定资产重大项目、产能利用率、在建工程转固及减值测试情况。
- 请逐项解释本报告中同比绝对变动达到20%的指标，并提供年报附注或管理层材料。
- 待补充：FY2024及FY2025短期借款主表可比值——已核对报表行未形成FY2024和FY2025短期借款数值事实；不能把空白单元格直接解释为零。
- 待补充：重大变动原因——V2.3已核对经营现金流等部分重大变动原因，但尚未覆盖每个重点科目的全部附注和管理层解释。
- V2.3专项：请说明净利润变动的具体原因，并提供利润变动桥接、毛利变动明细、期间费用与减值明细。
- V2.3专项：请说明经营活动产生的现金流量净额变动的具体原因，并提供经营现金流增幅的完整营运资金桥接。
- V2.3专项：请说明预付款项变动的具体原因，并提供主要预付对象、采购合同、履约进度、账龄。
- V2.3专项：请说明货币资金变动的具体原因，并提供受限资金明细、主要银行账户余额、资金变动构成。
- V2.3专项：请说明应付账款变动的具体原因，并提供主要供应商、采购背景、合同账期、逾期情况。
- V2.3专项：请说明营业收入变动的具体原因，并提供分产品销量价格桥接、重大客户订单、收入确认资料。
- V2.3专项：请说明流动资产合计变动的具体原因，并提供流动资产构成变动、受限及变现能力说明。
